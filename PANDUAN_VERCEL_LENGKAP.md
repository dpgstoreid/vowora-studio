# 🌐 Panduan Deploy Vowora ke Vercel (100% Gratis Selamanya)

Dengan Vercel, website **Vowora** kamu akan:
* ✅ **Online 24 Jam Non-Stop** tanpa laptop kamu harus menyala.
* ✅ **0 Cold Start (Tidak Pernah Tidur)**, buka halaman dalam hitungan 0.3 detik.
* ✅ **Gratis Selamanya** dengan sertifikat SSL (HTTPS) resmi.
* ✅ Bisa dipasang domain sendiri (contoh: `vowora.id` atau `vowora.my.id`).

---

## 3 Langkah Mudah Menghubungkan ke Vercel

### Langkah 1: Buat Repository Baru di GitHub
1. Buka browser dan kunjungi: **[https://github.com/new](https://github.com/new)**
   *(Jika belum punya akun GitHub, daftar gratis dalam 1 menit).*
2. Isi kolom **Repository name** dengan: `vowora` (atau nama lain yang kamu suka).
3. Pilih **Private** atau **Public** (bebas).
4. Klik tombol hijau **"Create repository"**.
5. Salin link repository kamu yang berakhiran `.git`, contohnya:  
   `https://github.com/username-kamu/vowora.git`

---

### Langkah 2: Upload Project Menggunakan File 1-Klik
Di dalam folder proyek Vowora:
1. Klik dua kali file: **`UPLOAD_KE_GITHUB.bat`**
2. Paste link GitHub yang tadi kamu salin, lalu tekan **ENTER**.
3. Selesai! Semua file Vowora sudah otomatis ter-upload ke akun GitHub kamu.

---

### Langkah 3: Deploy di Vercel (Hanya 1 Kali Klik)
1. Buka situs: **[https://vercel.com/new](https://vercel.com/new)**
2. Login menggunakan akun **GitHub** kamu.
3. Di daftar repository, kamu akan melihat repository **`vowora`**. Klik tombol **"Import"** di sebelahnya.
4. Pada halaman konfigurasi, **tidak perlu mengubah setting apapun** (karena file `vercel.json` sudah saya siapkan secara otomatis).
5. Klik tombol biru: **"Deploy"**!

Dalam waktu sekitar **30–45 detik**, website Vowora kamu sudah resmi mengudara di internet secara publik dengan domain gratis seperti:
👉 **`https://vowora.vercel.app`**

---

### 💡 Keuntungan Tambahan:
Setiap kali kamu mengedit atau menambah data undangan baru di laptop, kamu cukup upload lagi ke GitHub, dan Vercel akan otomatis memperbarui websitenya secara instan!
